## 🎙 О проекте

**VanGuard TTS API** — это адаптированный и обновленный TTS-сервер (Text-to-Speech) для проекта [VanGuard](https://github.com/VG-SpaceStation14/VanGuardSS14).

За основу взят оригинальный проект [ss14-tts-api](https://github.com/Rxup/ss14-tts-api). В данной версии мы перешли на новейшую русскую модель **Silero V5.6 RU**, которая обеспечивает высокое качество синтеза речи с автоматической расстановкой ударений и обработкой омографов. Подробнее о происхождении проекта и вкладе его авторов — в [CREDITS.md](CREDITS.md).

Для разнообразия мы внедрили систему **синтетических голосов**: 5 базовых голосов модели динамически изменяются по высоте тона (pitch), создавая **25 уникальных звучаний** (10 мужских и 15 женских), которые делятся на низкие, стандартные и высокие.

## ✨ Возможности

* **Silero V5.6 RU** — последняя русская модель с автоматической расстановкой ударений и буквы «ё».
* **25 уникальных голосов** — создаются на лету путем изменения питча базовых голосов (Aidar, Eugene, Baya, Kseniya, Xenia).
* **Умный парсер SSML** — сервер понимает сложные вложенные теги от C#-клиента (например, `<prosody pitch="+30%" volume="+3dB">`), сплющивает их и переводит в понятный для нейросети формат, удаляя неподдерживаемые атрибуты без потери интонации.
* **Звуковые эффекты** — встроенная обработка звука через FFmpeg: `Echo` (эхо), `Radio` (рация), `Robot` (робот).
* **Кастомные голоса** — возможность сохранять и использовать собственные `.pt` файлы голосов.
* **REST API** — простой и понятный интерфейс для интеграции с игровым сервером на C#.
* **Веб-интерфейс** — встроенная страница-тестер для быстрой проверки голосов и эффектов в браузере.

## 🛠 Архитектура и Стек

* **Язык:** Python 3.14+.
* **Нейросеть:** PyTorch (CPU-версия), Silero V5.6 RU.
* **Веб-фреймворк:** Flask.
* **Аудио-движок:** FFmpeg, SoundFile.
* **Тестирование:** Pytest (с моками для быстрой проверки без загрузки модели).

## 🚀 Установка и запуск

**Требования:** Python 3.14+, FFmpeg, libsndfile (для Linux).

1. Установите системные зависимости (на примере Arch Linux):
   ```bash
   sudo pacman -S ffmpeg libsndfile
   ```

2. Склонируйте репозиторий и перейдите в папку:
   ```bash
   git clone https://github.com/VG-SpaceStation14/VanGuard.TTS.git
   cd VanGuard.TTS
   ```

3. Создайте виртуальное окружение и активируйте его:
   ```bash
   python3.14 -m venv .venv
   source .venv/bin/activate
   ```

4. Установите Python-зависимости:
   ```bash
   pip install -r requirements.txt
   ```

5. Создайте файл конфигурации `.env` на основе примера:
   ```bash
   cp .env.example .env
   ```

6. Запустите сервер:
   ```bash
   python ss14tts.py
   ```

При первом запуске автоматически скачается модель `v5_6_ru.pt` (около 140 МБ) и выполнится прогрев базовых голосов.

## ⚙️ Конфигурация

Настройки сервера хранятся в файле `.env`. По умолчанию используются следующие значения:

* `PORT` — порт сервера (по умолчанию `5000`).
* `API_TOKEN` — токен для доступа к API (по умолчанию `test`). Обязательно поменяйте его на свой, если сервер доступен извне.
* `THREADS` — количество потоков CPU для PyTorch (по умолчанию `6`).

## 🔌 API Эндпоинты

* `GET /health` — проверка работоспособности сервера (возвращает `OK`).
* `GET /voices` — список всех доступных голосов (включая 25 синтетических и кастомные `.pt`).
* `POST /tts` — генерация речи.
    * Принимает JSON: `text`, `speaker`, `api_token`, `format` (ogg/wav), `effect` (Echo/Radio/Robot).
    * Возвращает JSON с аудио, закодированным в Base64.

## 🧪 Тестирование

В проекте настроены быстрые тесты, которые не требуют скачивания тяжелой модели. Запуск осуществляется через `pytest`:

```bash
pytest tests/ -v
```
