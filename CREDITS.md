# Credits & Acknowledgements

This project builds upon the original [ss14-tts-api](https://github.com/Rxup/ss14-tts-api) by **Rxup**, which provided the initial API foundation and inspiration for this implementation.

Since then, the project has undergone substantial development and adaptation for VanGuard SS14, including:

- Migration from Silero v3 to the latest Silero V5.6 RU model.
- Removal of StressRNN in favor of model-native processing (automatic stress and letter 'ё' placement).
- Implementation of a custom SSML parser to handle complex, nested prosody tags generated by the game client.
- Creation of a synthetic voice generator, expanding 5 base voices into 25 unique variants via dynamic pitch shifting.
- Clean FFmpeg audio processing for sound effects (Echo, Radio, Robot) without artificial distortion.
- An automated CI/CD pipeline with Pytest-based testing.
- Native systemd deployment, without requiring Docker.

We sincerely thank **Rxup** for the original project, its ideas, and the foundational work that made this development possible.

Thanks also to the [Silero team](https://github.com/snakers4/silero-models) for their speech synthesis models.
